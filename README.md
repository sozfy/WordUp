# 单词辅助背诵工具

纯前端英语背单词 + 离线词典查询工具，共六个页面。词表、单词与词典都存在浏览器本地，无需联网、无需服务器。

## 页面总览

| 页面 | 用途 |
| --- | --- |
| `index.html` | 首页，选择背单词或查单词 |
| `WordMemorizer.html` | 背单词：管理词表、随机抽背、选择题、拼写练习 |
| `DictLookup.html` | 查单词：ECDICT 离线词典查询 |
| `MyLists.html` | 我的词典：下载词典、管理词表、创建预设词表 |
| `User.html` | 用户：我的词表、每日任务、清除缓存 |
| `DailyTasks.html` | 每日任务：按日期给词表排艾宾浩斯复习 |

顶部导航统一为：左侧 logo，中间「背单词」「查单词」，右侧圆形「用户」图标（进入用户页）。

## 首页 `index.html`

- 中央两张功能卡片：「背单词」「查单词」
- 下方「使用说明」区块，三条简介

## 背单词 `WordMemorizer.html`

### 左侧「我的词表」侧栏

- 词表列表，点击切换当前词表
- 顶部「批量删除」：进入批量模式后勾选词表，底部「删除选中(N)」
- 「新建词表」：输入名称创建空词表（预设词表在「我的词典」页创建）
- 底部两个图标按钮：设置、添加单词

### 设置弹窗

| 设置项 | 说明 |
| --- | --- |
| 开启选择 | 显示多个释义选项，靠选出正确释义来记忆单词 |
| 选项个数 | 3~6 个，默认 4 |
| 详细释义 | 选项里的长释义不省略，全部展示 |
| 关闭手动确认 | 选项对错直接作为认识/不认识判定：选后 1 秒自动跳到下一个，并隐藏「认识/不认识」按钮；这 1 秒等待期内选项按钮锁定，连点无效 |
| 显示音标 | 在单词与释义之间显示一行音标；单词未揭示时先占位不显示，随单词一起出现 |
| 开启拼写 | 显示拼写输入框，输入后可对照单词着色 |
| 词意互换 | 主显示区显示释义、选项显示单词，按钮变为「显示单词」 |
| 单轮循环 | 本轮抽过的词不再重复出现，全部背完后弹统计；与记忆队列互斥 |
| 记忆队列 | 开始抽取时建立队列，不认识的词放回队尾；队列长度 3~10，默认 5；与单轮循环互斥 |

### 主显示区

- 「删除单词」：删除当前正在显示的单词（二次确认）
- 当前词表名、剩余单词数
- 上一个单词、当前单词、音标、释义
- 拼写输入框（开启拼写时可见）
- 选项区：最多 6 个按钮，作答后标记 √ / ×，正确为绿、错误为红
- 「开始抽取」「重置抽取」
- 「认识」「不认识」：需先显示释义才可点击
- 「显示意思」：词意互换开启时，按钮文字为「显示单词」

### 弹窗

| 弹窗 | 内容 |
| --- | --- |
| 新建词表 | 输入名称创建空词表 |
| 添加单词 | 每行一个单词；`word#释义` 可指定自定义意思，其余自动查词典，词典中不存在的会列出失败项；「从 Excel 导入」支持第 1 列单词、第 2 列意思、第 3 列助记、第 4 列音标（均可空）；另有「清空当前词表」 |
| 单词列表 | 单词总数、按数量拆分、与另一词表合并、搜索单词或释义、「保存到我的词典」、逐条查看详情或删除 |
| 单词详情 | 与查单词页同一版式的词条卡，「查看详细」跳转到查单词页 |
| 单轮循环结束 | 统计本轮认识与不认识数量，「删除已认识的单词」「拆分不认识单词」 |

## 查单词 `DictLookup.html`

- 「单词查询」：词典下拉 + 加载状态；搜索框回车或「查询」按钮触发；下方输入联想列表，按词频排序、词频高的优先
- 「查询结果」：词条卡包含音标、中文释义、英文定义、词性、时态变化、词典信息（柯林斯星级、牛津、词频等）；命中来自自己词表时显示「词表释义」与「助记」；词典未命中时先回退到自己的词表词条，仍无则给出前缀联想

## 我的词典 `MyLists.html`

### 已下载的词典

- 每本词典一行：名称、状态（已下载 / 未下载）、「下载」「重新下载」「删除」，按钮按状态自动禁用
- 行右侧箭头展开「预设词表」下拉：中考、高考、四六级、考研、雅思、托福、GRE，选中即创建词表。预设只存单词，创建时自动查词典补全释义与音标

### 我的词表

- 卡片列表，每张卡四个操作：查看、添加单词、添加到词表、删除
- 「查看」：搜索 + 单词列表 + 逐条删除 + 点击查看详情，版式与背单词页的词表一致（不含拆分 / 合并）
- 「添加单词」：文本输入或 Excel 导入，规则与背单词页相同
- 「添加到词表」：把整表单词并入另一个词表，按单词去重，来源词表保留
- 右下角「＋」新建空词表

## 每日任务 `DailyTasks.html`

入口在用户页的「每日任务」。

### 添加任务

- 词表下拉只列出还没有任务的词表；全部词表都已排期时显示「（词表都已添加任务）」并禁用「添加任务」
- 一个词表只排一次期：想换个首次学习日期，需先删除原任务，该词表才会回到下拉里
- 选好词表与首次学习日期后，下方即时预览各次复习落在哪一天，点「添加任务」生成排期

### 复习间隔（弹窗）

- 点「间隔设置」打开弹窗，弹窗内逐个设置第 n 次复习相对首次学习的间隔天数
- 默认 5 次：1、2、4、7、15 天；可在 1~8 次之间「增加一次」「减少一次」
- 第 n 次间隔不得小于第 n-1 次，填得更小会被自动抬到前一次的值
- 「保存并关闭」后，所有已建任务都按新间隔重新排期

### 任务清单

| 区块 | 内容 |
| --- | --- |
| 今日任务 | 今天到期的复习，标注「第 n 次复习」；右侧按钮在「完成」「已完成」之间切换，可撤销 |
| 未来安排 | 固定高度可滚动列表，一行一天：左侧日期，右侧当天复习摘要（词表名 + 第几次，同一天多个用 · 分隔），超出部分省略，悬停可看全文 |
| 已建任务 | 固定高度可滚动列表，一行一条：词表名、首次学习日期，右侧「修改」「删除」。修改只改首次学习日期，保存后按当前间隔重算全部复习节点，已勾选的完成状态保留；删除只移除排期，不动词表 |

日期已过而未勾选的复习不再显示，也不计入完成进度。

### 与词表的联动

- 词表在背单词页被删除（单个删除、批量删除、合并词表）时，对应全部每日任务一并删除
- 任务卡片上的词表名实时取自当前词表，词表改名后自动同步显示新名称

## 用户 `User.html`

竖向三项：

- 「我的词表」：跳转到我的词典页的词表区
- 「每日任务」：进入每日任务页
- 「清除缓存」：二次确认后清空本地全部数据并自动刷新

## 数据存放

词表、单词、词典都保存在浏览器 IndexedDB，少量开关设置存 localStorage。更换浏览器或清理浏览器缓存会导致数据丢失。
